# 七天假国庆小众旅行规划

一个面向国庆假期的旅行规划 Agent Skill。它会先了解出发地、日期、同行人、预算和交通方式，再比较目的地与往返路线，重点寻找人流压力较低、行程少折返的玩法，并把错峰安排、休息时间和拥堵替代方案写进攻略。

“小众”是筛选和规划的方向，不代表景点一定没人，也不保证假期当天不堵车。Skill 会区分已核实的信息、估算和未知项，并提醒在出发前复查容易变化的开放、预约、天气和交通信息。

## 安装

推荐使用 Skills CLI：

```bash
npx skills add wangguoqing123/qitianjia-guoqing-quiet-travel
```

按 CLI 提示选择你使用的 Agent。更新时重新运行安装命令。Skills CLI 支持多种 Agent Skills 宿主；实际能调用哪些浏览器、地图、天气和文件工具，取决于宿主本身。

也可以手动安装：把本仓库完整复制到所用 Agent 的 Skills 目录，并保留 `SKILL.md`、`references/`、`scripts/` 和 `assets/` 的相对位置。以 Codex 为例，放在 `$CODEX_HOME/skills/qitianjia-guoqing-quiet-travel/`；如果没有设置 `CODEX_HOME`，通常是 `~/.codex/skills/qitianjia-guoqing-quiet-travel/`。安装后按宿主说明重新加载或开启新对话。

## 使用

安装后，在新对话中直接描述需求，例如：

> 调用七天假国庆小众旅行规划 Skill。我们从杭州出发，国庆玩 5 天，自驾，两个大人带一个孩子，预算 8000 元。希望少换酒店、每天别排太满，先帮我比较几个目的地方向。

如果目的地已经定好，可以直接要求规划完整行程：

> 国庆 10 月 2 日从绍兴出发，自驾去安徽玩 4 天，2 个大人带一个 4 岁孩子。请优先考虑小众玩法和错峰，安排午休、少换酒店，并给出停车排队或下雨时的替代路线。

想调整时，继续在同一对话补充要求，例如“第二天轻松一点”“不要早起”“这处景点一定要去”或“如果停车场满了，给我一条能接回主路线的备选安排”。

## 提供这些信息会更好

- 出发地、日期、可玩的天数，以及日期是否灵活
- 同行人和体力特点，例如儿童年龄、长辈步行能力
- 自驾、公共交通或其他方式；是否已有车票、酒店或门票
- 总预算及是否包含交通、住宿
- 想看的主题、必去地点，以及不想要的玩法
- 对早起、换酒店、步行、排队和堵车的接受程度

不必一次填完。信息不全时，Skill 可以先比较方向，说明采用的假设和仍需确认的事项。

## 能做什么

- 比较目的地及出发、当地游玩、返程的完整交通链路
- 按具体日期和时段研究开放、预约、活动、客流信号和交通限制
- 按片区编排行程，考虑停车、步行、用餐、休息和机动时间
- 为停车排队、道路拥堵、预约失败或天气变化安排可执行的替代方案
- 生成结构化行程数据、Markdown 攻略和可离线打开的单文件 HTML
- 在工具与素材许可允许时，为攻略加入地点照片；无法确认图片许可或地点时会改用文字说明
- 复核或修改已有行程，并保留先前版本

## 工具与限制

基础规划和文件生成使用随 Skill 提供的 Python 脚本与标准库，不需要安装 Python 第三方包。建议使用 Python 3.10 或更高版本。

实时研究依赖 Agent 宿主当前提供的联网搜索、网页读取、地图、天气和文件工具。缺少某项工具时，Skill 应说明限制并标记未知，不能假装查过。可选 TikHub 小红书数据接口需要使用者自行配置凭据，可能产生费用；基础规划不要求配置，也不会自动调用付费接口。

客流和路况会因天气、临时活动和假期变化。攻略中的判断以记录的核查时间和证据为准，请按攻略标记在出发前复查。Skill 不代替官方公告、地图导航和现场指引，也不会替用户预订、付款、取消或改签。
